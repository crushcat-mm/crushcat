## 🚀 如何打開網站

直接用滑鼠**雙擊 `index.html`**，就會用瀏覽器打開。

要放到網路上？把 `index.html` 上傳到任何虛擬主機或 GitHub Pages 即可。

## ✏️ 最常改的 5 件事

### 1. 改電話、地址、LINE 等基本資料

打開 `index.html`，搜尋 `【店家資料】`，大約在第 430 行附近。

你會看到：

```javascript
phone: "0905603028",        ← 改電話
lineId: "@389kzxeb",         ← 改LINE ID
address: "台中市南屯區...",  ← 改地址
lineLink: "https://...",     ← 改LINE連結
ig: "https://...",           ← 改IG連結
fb: "https://...",           ← 改臉書連結
parking: "https://...",      ← 改停車場地圖連結
gmaps: "https://...",        ← 改店面地標連結
```

**只要改引號裡面的文字，其他不要動。**

---

### 2. 加一隻新貓咪

搜尋 `【待售貓咪列表】`，大約在第 500 行附近。

你會看到每一隻貓長這樣：

```javascript
{
  name: "奶茶",
  breed: "英國短毛貓",
  color: "藍金漸層",
  birthday: "2026/03",
  price: "面議",
  img: SHOP.newCat6,   ← 貓咪照片
  desc: "溫親人，愛撒嬌"
},
```

**複製一整塊 `{ }`，貼在最後一隻貓的後面，改掉裡面的資料就好。**

照片要先上傳到圖床（如 imgur），拿到網址後加在 `【圖片網址】` 區塊，然後在貓咪的 `img:` 欄位引用。

---

### 3. 改圖片

搜尋 `【圖片網址】`，大約在第 450 行附近。

每張圖都有一個變數名稱和網址：

```javascript
bgImage: "https://...",    ← 全站背景底圖
topBanner: "https://...",  ← 頂部橫幅
logo: "https://...",       ← Logo
banner: "https://...",     ← 首頁大圖
```

**把新圖片上傳到圖床，拿到網址，取代引號裡的舊網址就好。**

---

### 4. 加一個新頁面（進階）

步驟：

1. 搜尋 `【選單】`，在 NAV 陣列加一列：
   ```javascript
   {label:"新頁面", href:"#newpage"}
   ```

2. 搜尋 `【頁面函式】`，加一個新函式：
   ```javascript
   function pageNewpage(){
     return `
     <section class="section">
       <div class="container">
         <h2>新頁面標題</h2>
         <p>頁面內容</p>
       </div>
     </section>`;
   }
   ```

3. 搜尋 `PAGES = {`，加一行：
   ```javascript
   newpage: pageNewpage,
   ```

完成！

---

### 5. 改常見問題（FAQ）

搜尋 `【常見問題】`，大約在第 640 行附近。

每一題長這樣：

```javascript
{
  question: "問題文字？",
  answer: "答案文字。"
},
```

複製貼上、改掉文字就好。

## ⚠️ 注意事項

1. **絕對不要用 Word 記事本以外的文書軟體改檔案**，會壞掉。請用「記事本」或 VS Code。
2. 改完記得**存檔（Ctrl+S）**，然後重新整理瀏覽器。
3. 圖片建議用 **jpg 或 png**，寬度至少 1000px。
4. 所有連結記得加 `https://` 開頭。
